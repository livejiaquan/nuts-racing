# 核果賽車 Nuts Racing

核果資訊學苑高雄校 micro:bit 自走車班的 3D 網頁賽車遊戲。Three.js，高雄濃縮版賽道（85 大樓、愛河大橋、高雄港、駁二、巨蛋、美麗島站），可以用鍵盤玩，也可以把 micro:bit 用 USB 接上當體感方向盤。

- 線上玩：https://livejiaquan.github.io/nuts-racing/
- 鍵盤：方向鍵開車，Enter 開始
- micro:bit：先把 `microbit程式/方向盤.hex` 燒進板子（拖進 MICROBIT 磁碟），用 Chrome 或 Edge 開上面的網址，按「連接 micro:bit」選 mbed Serial Port。左右傾斜轉彎，B 油門、A 煞車。

細節看 `先看我_遊戲說明.md`。
